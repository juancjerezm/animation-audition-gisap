# Skill: GSAP ScrollTrigger Landing Animations

El agente debe saber crear landing pages con:  

- GSAP  
- ScrollTrigger  
- timelines  
- pin  
- scrub  
- stagger  
- hover animations  
- product transitions  
- scroll storytelling  

Reglas:  

- Usar transform y opacity para rendimiento.  
- Evitar animar width, height, top, left si no es necesario.  
- Usar timelines limpias.  
- Hacer responsive.  
- No abusar de blur en móvil.  
- La sección principal debe usar ScrollTrigger con pin y scrub.
